# Admin portal (`apps/admin`)

Internal Next.js App Router application. This origin remains non-indexable and provides booking operations at `/bookings`, driver management at `/drivers`, and vehicle management at `/vehicles`. Phase 8 lets administrators create and maintain real fleet records, preserve temporal driver/vehicle roster history, and assign eligible resources after booking acceptance. Admins use the shared phone OTP flow; the API's persisted `admin` role remains the authorization boundary.

Fleet lists are paginated and searchable. Driver numbers are generated by the API, roles are never browser-selected, and deactivation preserves historical records. Candidate lists are loaded through admin BFF routes and capped at 100. Empty/loading/conflict states are explicit. Acceptance and booking assignment are separate confirmations; Phase 8 does not support booking reassignment or unassignment.

```bash
npm install
npm run dev    # http://127.0.0.1:43122
npm run build
```
